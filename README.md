# GSAP и плавный скролл — урок для веб-дизайнеров

Интерактивная страница-урок: что такое GSAP, язык анимации, easing, каскад, таймлайн, анимации от скролла (ScrollTrigger), эффекты (SplitText, Flip, Draggable, MotionPath, DrawSVG, MorphSVG, ScrambleText), плавный скролл на Lenis, популярные приёмы и как писать ТЗ на анимацию. Все примеры живые, к каждому есть готовый промпт для нейронки.

## Структура

```
index.html      — страница
css/style.css   — стили
js/main.js      — демо и логика
```

Библиотеки (GSAP 3.15.0, Lenis 1.3.26) и шрифты (Inter Tight, JetBrains Mono) подключаются по CDN, установка не нужна.

## Запуск

Откройте `index.html` в браузере. Нужен интернет.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите содержимое архива в корень.
2. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.
