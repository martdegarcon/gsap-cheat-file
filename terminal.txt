1) Копируем команды с гита и вставляем в терминал
2) прописываем поочередно следующие команды

git add .
(добавляет все файлы в следующий коммит гита)

git commit -m "second commit"
(называем наш следующий коммит как угодно)

git push
(отправляем наш коммит в гитхаб)

Файл сайта должен называться index.html!
Поэтому меняем названием с GSAP и плавный скролл.html -> index.html
